# 🌐 Personal Web Portfolio — Andi Taufiq Zuhair Pangeran

Proyek landing page portofolio pribadi yang dirancang menggunakan **HTML5 & CSS3 Murni (Vanillas)** secara responsif, bersih, dan modern. Mengangkat latar belakang sebagai mahasiswa Teknologi Informasi dengan spesialisasi di bidang **Frontend Web Development** dan **Cybersecurity**.

---

## ✨ Fitur Utama

- **Hero Header & Profile Showcase**: Menampilkan identitas, peran utama, dan foto profil dengan efek elevasi visual.
- **Responsive Layout**: Menggunakan CSS Flexbox dan Grid untuk penyesuaian otomatis di perangkat mobile, tablet, maupun desktop.
- **Interactive Project Cards**: Card interaktif dengan efek transisi *hover* untuk menampilkan portofolio proyek unggulan.
- **Badges Keahlian & Sertifikasi**: Struktur visual badge untuk keahlian teknikal serta daftar pencapaian/sertifikasi.
- **Social Media Links**: Tombol tautan media sosial interaktif menggunakan ikon FontAwesome.
